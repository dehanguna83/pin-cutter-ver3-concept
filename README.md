# Pin 절단기 VER.3 R05

2026-11-02 · 구조 배치와 작동 원리를 확인하는 컨셉 모델

**[R05 3D 모델 열기](https://dehanguna83.github.io/pin-cutter-ver3-concept/)** · [R04 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-04.html) · [R03 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-03.html) · [R02 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-02.html) · [R01 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-01.html)

R05에서는 보조지지대의 실제 하중 경로, 대기열의 최단 밀착과 받침 높이, 본체 안으로 들어간 이송 장치, X 커버와 일치하는 후면을 검토합니다. 절단석은 기존 모터·풀리·벨트·스핀들로 구동합니다.

| 화면에서 선택 | 확인할 변경 |
|---|---|
| **보조지지** | **보조지지 밀착**과 **간격 펼치기**로 2 mm 접촉부와 이를 받치는 안내·지지 구조를 확인합니다. 초기 마스터 정렬은 추가 설정으로 접어 두었습니다. |
| **대기·이송** | **대기열 최단 밀착**으로 다섯 대기핀의 받침도 주 Z와 같은 면간격 0까지 모이는지 확인합니다. 두꺼운 지지 몸체를 서로 다른 안내 경로에 배치하고 바닥을 올렸습니다. **한 사이클 보기**로 워킹빔 인계와 가공 위치 복귀를 봅니다. |
| **전체** | 대기이송 장치와 닫힌 탈착커버가 본체의 기존 전면·우측면 안에 있습니다. 모터 베드는 기초판에 체결되며, 전면 손잡이는 매립형입니다. |
| **후면·우측** | 하부 외장과 Z 구동 커버를 X 커버의 실제 후면에 맞췄습니다. 프레임과 후방 하강 받이도 그 안으로 조정했습니다. |
| **좌측 정비** | 색상이 다른 X 좌측면 전체가 뒤쪽 수직 힌지로 열립니다. 매립 래치와 패킹을 유지하고 후면 밖으로 나오던 힌지를 조정했습니다. |
| **하강 받이** | R04의 단핀 받이, 별도 헤드 지지, 하강 후 회전과 고무 경사로 배출을 유지합니다. |
| **장척** | 착탈식 연장봉의 헤드 끝 기준면을 **1,000 mm 초과~1,700 mm**에서 수동 설정합니다. 자동 이송은 정지합니다. |

주 지지대는 C1 20 mm, 보조 세 개 각 2 mm, C2 10 mm로 면간격 0에서 폭 합계가 **36 mm**입니다. 이 값은 생산 가능한 최소 완성길이가 아닙니다. 실제 최소길이는 헤드, 절단 위치, 가압부와 이송 여유를 함께 검토해 결정합니다. 자동 범위는 헤드 끝면까지 최대 **1,000 mm**입니다.

주 Z 보조지지대는 C1·C2 하부 몸체에 단차를 주어 확보한 공간에 두꺼운 지지 기둥 세 개를 깊이 방향으로 나눠 넣었습니다. 두 높이의 안내부가 기둥의 위치와 비틀림을 구속하고, 연속 지지 베드로 힘을 전달합니다. V 가까이까지 두꺼운 기둥을 올려 2 mm 끝판의 지지되지 않는 높이를 줄였습니다. 초기 마스터 정렬은 조립 오차를 보정하는 추가 설정입니다.

단핀 셋업에서는 중앙 포크·가이드를 수동 분리해 하부 선반에 보관하고 양끝 포크와 별도 헤드 받침으로 이송합니다. 하강 받이 팁도 단핀 체결 위치로 바꿉니다. 이 변경은 정지 상태의 수동 셋업입니다. 예시 헤드 외경은 몸통 지름+10 mm, 두께는 6 mm이므로 실제 핀 규격에 맞춘 확인이 필요합니다.

외곽 일치는 닫힌 대기이송 장치·커버 기준입니다. 조작판을 앞으로 꺼내거나 정비문·트레이를 열 때는 별도 점유 공간이 필요합니다. 수동 장척 연장봉도 사용하는 동안 본체 밖으로 나옵니다.

이 모델은 제작 도면이나 강성 검증 결과가 아닙니다. 실제 가이드의 예압·유격, 지지 높이 반복성, 2 mm 접촉부의 강도, 3 kN 가압 시 V·요크·체결부 변형, 공차·진동·누수·집진 성능은 상세 설계와 실물 확인 대상입니다. 초기 마스터 정렬로 구조 강성이 확보되지는 않습니다.

드래그로 회전하고 휠로 확대합니다. **현재 모델 저장**은 보이는 상태를 GLB로 내려받습니다. R01~R05의 단독 HTML에는 Three.js와 Draco가 포함되어 있습니다. [라이선스 및 저작자 고지](./THIRD_PARTY_LICENSES.txt)

대기핀은 착좌 위치보다 2 mm 앞에서 대기합니다. 당김판은 초기 기준면 여유 12 mm와 총 6 mm 행정을 유지하며, 4 mm 접근 후 마지막 2 mm에서 핀을 밀착시킵니다. 최단 배치의 Ø30 예시는 정적 무게중심의 지지 여유가 약 1.1 mm로 작으므로, 축방향 대기 기준·공차·진동 검증을 거쳐 최소 완성길이를 정해야 합니다.

# Pin cutter VER.3 concept

기존 모터·벨트·풀리·스핀들 구동을 유지한 3D 구조 검토 모델입니다.

GitHub Pages는 이 저장소의 main / root를 게시 소스로 설정합니다.
index.html 한 파일에 모델·뷰어·필요한 라이브러리가 들어 있습니다.
서버가 없어도 index.html을 Edge/Chrome에서 직접 열 수 있도록 구성했습니다.

회전·확대, 지지대 간격, 클램프, 공통 Z, 워킹빔과 전면 회수 동작을 확인할 수 있습니다.
현재 상태를 GLB 모델로 내려받을 수 있습니다.

제작용 CAD나 간섭·강도 승인 결과가 아닌 개념 검토 모델입니다.
C1 20 / 보조 2×3 / C2 10 mm, 동일 면간격 배분을 표현합니다.
g<35 mm는 짧은 핀의 이송 포크 배치가 미확정이므로 정적 검토로 제한합니다.
프레임·클램프·링크·워킹빔의 연속 간섭, 강성, 제조 치수는 후속 검토 대상입니다.

Three.js 0.180.0 (MIT), Draco glTF decoder (Apache-2.0).
독립 HTML 소스와 THIRD_PARTY_LICENSES.txt에 원본 라이선스·저작자 고지를 함께 보존했습니다.

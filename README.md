# Pin 절단기 VER.3 R02

[R02 3D 모델 열기](https://dehanguna83.github.io/pin-cutter-ver3-concept/) · [이전 R01 모델 열기](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-01.html)

R02에서는 대기핀 5개와 대기 받침을 **공급 기준 +165 mm** 위치에 둡니다. 「대기열과 워킹빔」에서 「한 사이클 보기」를 누르면 완료핀을 잡은 공통 Z가 공급 위치로 이동합니다. 클램프와 헤드 기준부가 물러난 뒤 공정측 포크 노즈가 전개되고 워킹빔이 한 피치 움직여 새 핀을 공급 좌표의 C1·C2 받침에, 완료핀을 후방 인계받이에 놓습니다. 공통 Z는 새 핀을 착좌·클램핑한 뒤 가공 위치로 복귀합니다. 완료핀은 후방 인계받이의 하강과 기울임을 거쳐 베이스 아래 고무 라이너 슈트에서 전면 트레이로 이동합니다.

| 검토 부위 | 모델에서 확인할 수 있는 내용 |
|---|---|
| Z축과 지지부 | C1 20 mm, 보조지지 3개 각 2 mm, C2 10 mm의 밀착·등간격 셋업. 헤드 어깨 착좌, C1 LM 레일 브레이크와 C2 원형봉 브레이크의 교대 체결 |
| 절단·연마부 | 기존 모터·풀리·벨트·스핀들 구동, 연마측 수동 미세 이동 50 mm, 절단·연마 두 습식 존과 숫돌 정비를 위한 축 퇴피·도어 개방 순서 |
| 하부 회수·전장 | 절단 잔재 바스켓, 연마 슬러지 필터와 절삭유 회수, 두 흡입 분기의 공용 습식 집진실, 완료품 수납 트레이, 전장 격벽과 정비 출입 공간 |
| 핀 측정 | 정지·세정·퍼지 뒤 보호 셔터와 광학 카세트를 전개하고 핀 끝면과 외경을 주사하는 동작 |

**짧은 핀.** 지지 블럭의 인접 면간격을 `g`로 표시합니다. `g = 0`에서 받침 폭의 합계는 36 mm입니다. `g < 42 mm`에서는 이송 포크를 제외한 밀착 배치를 확인할 수 있습니다. 짧은 핀용 포크와 헤드·공구 여유를 정한 뒤 최소 자동 이송 길이와 최소 완성길이를 각각 산정해야 합니다.

**클램프 하중.** 모델은 각 클램프의 3 kN 목표 하중이 요크·핀·V 블럭·프레임으로 전달되는 경로를 보여줍니다. 실제 가압력, 프레임 처짐과 체결부 강도, 브레이크 보유력·응답은 선정 부품의 정격과 시제품 하중 시험으로 확인해야 합니다. 공통 Z의 편도 165~180 mm, 왕복 330~360 mm 이동에 따른 이동질량·가감속·사이클 시간도 후속 검토 항목입니다.

**툴세터.** Renishaw NC4+ Blue F145를 비접촉 측정 후보로 두었습니다. 정지 금형핀에 대한 적용, 수직 광축 설치, 물방울·유막 제거와 퍼지, 제어기의 양쪽 에지 검출을 공급사와 확인해야 합니다. 길이·외경 정확도는 축 보정 후 Ø1·Ø30을 포함하는 기준핀으로 검교정해야 합니다. [제조사 제품 자료](https://www.renishaw.com/en/advanced-laser-tool-setters-for-cnc-machines--6099)

뷰어에서 회전·확대하고 「현재 모델 저장」으로 보이는 상태를 GLB로 내려받을 수 있습니다. 실부품 전 구간 간섭, 동적 배출, 누액·여과·집진 성능과 숫돌 방호는 제작 설계 및 실물 시험 단계에서 확인해야 합니다.

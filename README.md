# Pin cutter VER.3 — R06

기존 절단석 모터·풀리·벨트 구동을 유지하는 기구 배치 검토 모델입니다.

## R06 변경

- ISO 6751 원통 머리 핀의 지름별 헤드 치수와 질량을 적용하고 대기 받침 중앙을 무게중심에 맞춤.
- 헤드를 초기 12 mm 간격의 중앙에 놓고, 헤드 두께에 따라 접근·착좌 행정을 조정.
- 최단 대기열의 포크와 하부 통과 경로 수정.
- 장척 기준면과 이송 모터가드·편심 구동부의 간섭 수정.
- Z 구동 커버 아래 분할 탈착 하판, 폐쇄된 조작판 매립 포켓.
- 완료품 트레이의 뒤쪽 바닥과 레일 연장. 150 mm 인출에서도 슈트 출구와 바닥이 54 mm 겹침.
- 숫돌 도어의 내부 측벽 링크·뒷면 브라켓, 좌측 정비문의 손넣음 손잡이와 겹침 마감.

‘대기·이송’에서 지름과 최단 밀착을 선택하면 헤드 양쪽 여유와 무게중심 보정을 볼 수 있습니다. 길이·지름이 바뀌는 셋업 때 저상 장공의 보정값을 맞추고 잠그는 개념입니다. ‘습식 숫돌실’, ‘좌측 정비’, ‘장척’ 및 ‘전체’의 조작판·서랍 조절로 다른 변경을 확인합니다.

## 규격과 해석

헤드 치수는 [ISO 6751:2011](https://www.iso.org/standard/57874.html)의 원통 머리 핀을 기준으로 합니다. Ø1은 [제조사 보완 치수](https://eberhard-precision.de/wp-content/uploads/2021/03/Stainless-and-acid-resistant-ejector-pins.pdf), Ø30은 ISO Ø32 소재의 헤드를 유지한 특수 치수 예시로 표시합니다. 모든 지름·길이 조합이 표준 공급품이라는 뜻은 아닙니다.

최소 완성길이는 미정입니다. 정적 무게중심과 공칭 형상의 표본 검사이며, 실제 강성·3 kN 변형·공차·처짐·동적 이탈·누액 및 안전 성능은 상세 설계와 실물 검증 대상입니다.

브라우저에서 회전·확대하고 현재 상태를 GLB로 저장할 수 있습니다. Three.js와 기존 X 형상, 디코더를 단독 HTML에 포함했습니다.

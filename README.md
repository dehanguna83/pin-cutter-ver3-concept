# Pin 절단기 VER.3 R03

**[R03 3D 모델 열기](https://dehanguna83.github.io/pin-cutter-ver3-concept/)** · [R02 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-02.html) · [R01 비교](https://dehanguna83.github.io/pin-cutter-ver3-concept/revision-01.html)

핀 길이 **1,000 mm까지**는 5개 대기열과 워킹빔으로 자동 이송합니다. **1,000 mm 초과부터 1,700 mm까지**는 착탈식 연장봉으로 헤드 끝 기준면을 맞추고 한 개씩 수동 투입하는 장척 셋업을 검토합니다. 절단석은 기존 모터·풀리·벨트·스핀들로 구동합니다.

| 화면에서 선택 | 확인할 동작 |
|---|---|
| **장척** | 기본 기준판을 빼고 연장봉을 장착합니다. 마스터 환봉의 실제 길이를 입력한 뒤 「기준면 맞춤」을 눌러 헤드 끝 위치를 정합니다. 외부 받침의 지지점과 연장봉 위 기준면의 잠금 위치를 살펴볼 수 있습니다. 장척 셋업 중에는 자동 이송을 차단합니다. |
| **Z·클램프 / 정렬** | C1·C2의 공용 역V 가압발이 Ø1~30 핀의 상부를 누릅니다. 정렬 작업에서는 Ø30 × 1,000 mm 마스터 핀과 임시 받침으로 축선을 잡습니다. S1·S2·S3를 각각 선택해 잠금을 풀고 높이·좌우 중심·기울기를 맞춘 뒤 다시 잠급니다. |
| **대기·이송** | 대기열은 공급 기준 +165 mm에 고정됩니다. 공통 Z가 완료핀을 공급 위치로 가져가면 워킹빔이 한 피치를 이송합니다. 후방 받이의 다섯 V 지지점은 길이 셋업에 맞춰 간격을 바꾸고 잠깁니다. 완료핀을 받은 뒤 받이가 먼저 하강하고, 하강 저점에서 회전해 고무 라이너 슈트로 넘깁니다. 핀은 베이스 아래를 지나 전면 트레이로 나옵니다. |
| **전체 / 좌측 정비** | 매립형 HMI를 기계 전면으로 꺼낸 뒤 좌위·입위에 맞춰 높이와 화면 각도를 조절합니다. 좌측 상부 서비스문을 위로 열고 외장 패널을 분리해 X축 정비 개구를 확인할 수 있습니다. |
| **하부 회수** | 집진기와 탱크·펌프는 각각 받침판과 고정 레일에 설치됩니다. 정비문을 열고 대차를 도킹한 뒤 연결부와 고정구를 해제하면 집진기는 전면, 탱크·펌프는 좌측으로 받침판과 함께 인출됩니다. |

「한 사이클 보기」는 자동 범위에서 지지 블럭의 인접 면간격 `g`가 42 mm 이상이고 셋업·정비가 끝난 상태에서 작동합니다. 최단 밀착 시 C1 20 mm, 보조 3개 각 2 mm, C2 10 mm의 받침 폭 합계는 36 mm입니다. 실제 최소 완성길이는 헤드·가드·이송 포크의 여유를 포함해 결정해야 합니다.

Ø1 × 1,700 mm 강재 핀은 외측 받침에서 헤드까지 약 358 mm가 남습니다. 균일한 원형축에 자중만 작용하는 단순 외팔보로 보면 끝 처짐은 약 12 mm입니다. 이 조합은 추가 받침의 위치를 정하고 실측해야 합니다.

실물 검토에는 소경핀에 맞는 가압력과 표면 손상, 3 kN 목표 하중에서의 프레임·체결부 처짐, 장척핀의 자중 처짐과 외부 받침 정렬, 하강·회전 받이의 정지·잠금 검출이 남아 있습니다. 습식 환경에서의 광학 툴세터 측정은 퍼지 조건과 기준핀 검교정이 필요합니다.
